# 灸法操作与壮数

> 出处：《针灸大成》卷四/卷十/卷十一、《备急灸法》（宋·张涣）、《扁鹊心书》（宋·窦材）
> ⚠️ 古籍记载仅供学习。现代施灸以**温热不灼痛**为度，勿照搬「百壮」等古量。

## 1. 为何用灸（古籍依据）

《针灸大成》：
> 「为什么要灸？当针力不及的地方，我们就会用到灸，**气血大虚时，可用灸的方式处理**。」

《扁鹊心书》（窦材）核心主张：
> 「**保命之法，灼艾第一**，丹药第二，附子第三。」

即：虚寒、阳虚、气血大虚之证，灸法优先于药。

## 2. 艾的特性（古籍说明）

《针灸大成》原文：
> 「用灸时就必须用『艾绒』……艾草它生命力很强，再艰难的环境下都可以找得到它。**艾有一个特性，就是向下**，艾会自己去找水，找到水以后烟就往上升。」
> 「**因为艾本性向下，它的本性是属阳的。**」

## 3. 常用灸法

| 灸法 | 操作（古籍原文要点） | 适应症 |
|---|---|---|
| **隔姜灸** | 切一片生姜（约硬币大小），先戳几个洞；艾绒捏成金字塔状放在生姜上 | 最普遍；膏肓灸百壮；心脏病灸关元 |
| **隔盐灸** | 青盐炒熟，填满神阙（肚脐） | 霍乱下利；**神阙穴专用**（神阙禁针宜灸） |
| **隔蒜灸** | 蒜片放舌上灸 | 久咳；肺病 |
| **米粒灸** | 艾绒米粒大 + 凡士林固定 | 鼻窦炎（灸上星）；鸡眼；肿瘤 |

### 隔姜灸操作细节（原文）
> 「所谓隔姜灸就是切一片大概五十元大小的生姜，先戳几个洞……拿一些艾绒捏成金字塔状，再将它放在生姜上面，**这样一个单位叫一『壮』**。在灸的时候，这个生姜片不用换……**烧到温热，不用烧到很烫**。感觉温热不用很烫时就换一壮，在旁边放一个水盆，未烧完的艾就丢到水里熄灭掉。」

### 起水泡的处理（原文）
> 「若灸后起了水泡，就从皮肤旁用消毒过的针刺一个小洞，把水慢按排出来。**不要把皮肤撕掉免得造成疤痕**，洒上一些硫磺粉及大黄粉就可以了。」

## 4. 灸法总则（原文）

| 原则 | 原文 |
|---|---|
| 气血大虚用灸 | 「气血大虚用灸」 |
| **壮数取单数** | 「**灸单数不灸双数，艾为纯阳，取阳数**」 |
| 热症不灸 | 「热症不灸」 |
| 针灸分开 | 「针灸分开」 |

| 关元 | 灸七壮；又云灸百壮止三百壮 | 卷九 |

## 6. 施灸流程（现代安全实践）

1. **施灸前**：确认无禁忌（见 `02-safety-contraindications.md`）；排空、勿空腹或过饱
2. **体位**：舒适稳定，暴露穴位，注意保暖
3. **定位**：按古籍定位或现代骨度分寸法取穴
4. **施灸**：艾条距皮肤 **3–5 cm**，温热舒适为度；每穴 10–15 分钟
5. **观察**：皮肤微红即可；**出现灼痛立即抬高**
6. **灸后**：彻底熄灭火种；通风；2 小时内勿洗冷水、勿吹风；适量温水
7. **频次**：保健灸每周 2–3 次；治疗性灸遵医嘱

## 7. 现代常见对应（非古籍，供参考）

| 古籍灸法 | 现代常见形式 |
|---|---|
| 艾炷灸（一壮） | 艾条悬灸 / 艾炷灸（小炷） |
| 隔姜灸 | 隔姜灸（仍常用） |
| 隔盐灸（神阙） | 隔盐灸 / 温和灸神阙 |
| 米粒灸 | 麦粒灸（现代称法） |

艾条灸分：**温和灸**（固定距离，最常用）、**雀啄灸**（上下移动）、**回旋灸**（左右移动）。
