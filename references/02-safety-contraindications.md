# 安全边界与禁忌

> **本文件是使用艾灸前必读的安全清单。**
> 本 skill 是古籍文献检索工具，**不是诊断或治疗建议**。以下内容综合古籍禁忌 + 现代安全实践。

---

## 1. 绝对禁忌：不要灸

| 情形 | 说明 |
|---|---|
| **发热 / 热证** | 发烧、感冒发热、口渴喜冷、便秘燥结、舌红苔黄。古籍明训：**「热症不灸」** |
| **阴虚火旺** | 五心烦热、潮热盗汗、口干咽燥、舌红少苔、失眠多梦伴烦躁 |
| **实热疮疡** | 红肿热痛的感染灶、痔疮、丹毒 |
| **特殊部位** | **眼睛、阴部、乳头（乳中）**。古籍：乳中「禁灸，灸则生蚀疮」 |
| **皮肤破损处** | 溃疡、伤口、皮疹、感染区 |
| **孕期** | **腹部、腰骶部禁灸**；合谷、三阴交亦禁针（古籍：「妇人禁针禁灸，犯之绝子」指石门） |
| **醉酒 / 大汗后 / 行房后** | 古籍：「喝酒后不针」「行完房事后也不针」「运动过后、大汗后也不针」 |
| **极度虚弱 / 大失血后** | 需专业判断，不可自行大灸 |

## 2. 古籍明载禁灸穴位（据《针灸大成》）

完整数据见 `data/moxa_forbidden.json`，可用 `query.py forbidden` 查询。
**注意：禁灸记载在各典籍间存在分歧**，下列已分类。

### 2.1 明确禁灸（另无灸量记载）—— 17 穴

| 穴位 | 禁灸出处 | 古籍所述后果 |
|---|---|---|
| 乳中 | 铜人 | 灸则生蚀疮，疮中有脓血；疮中有息肉、蚀疮者死 |
| 风府 | 铜人 | 灸之使人失音 |
| 大椎 | 素注/铜人 | 灸之令人□（原文缺字，通作「瘖」，即失音） |
| 脑户 | 铜人 | 灸之令人□（同上）；素问：刺脑户，入脑立死 |
| 脊中 | 铜人 | 灸之人腰伛偻 |
| 经渠 | — | 灸伤神明 |
| 伏兔、天府、委中、承光、漏谷、眉冲、迎香、阴市、阳关、头维、鱼际 | 铜人（多数） | 未载具体后果 |

> **委中尤需注意**：腰痛常被推荐灸委中，但《针灸大成》明载「**委中禁灸**」，主张**放血**（「四畔之紫脉上，皆可出血」）。

### 2.2 典籍分歧（同条既言禁灸、又载灸N壮）—— 11 穴

`下关、劳宫、太杼、扶突、攒竹、石门、丝竹空、耳门、肩井、阳池、鸠尾`

例：**耳门**「铜人针三分，留三呼，**灸三壮**，下经**禁灸**，**病宜灸者，不过三壮**」——即分歧中给出了折中上限。
**这类穴位须由执业医师判读，不要自行施灸。**

### 2.3 已剔除的解析噪声（6 条，非穴位）

`名医治法`、`治病要穴`（章节标题）、`艾叶`（药名）、`二伏兔`/`小商`/`丝竹`（切分或形近误字，真身已单列）。
记录于 `moxa_forbidden.json` 的 `noise_dropped` 字段，保留审计痕迹。

## 3. 高危人群（必须医生指导，不可自行灸）

| 人群 | 风险 |
|---|---|
| **糖尿病 / 周围神经病变** | ⚠️ **最高风险** —— 感觉减退，**极易烫伤且伤口难愈**，可致溃疡、坏疽 |
| **血液循环障碍 / 静脉曲张** | 局部血供差，愈合不良；曲张静脉处禁灸 |
| **服抗凝药、凝血异常** | 易出血、瘀伤 |
| **心脏病 / 严重慢性病** | 需专业评估 |
| **婴幼儿** | 皮肤薄、耐受力差，须专业操作 |
| **高龄体弱者** | 感觉与修复能力下降 |
| **孕妇** | 腹部、腰骶禁灸 |
| **感觉障碍 / 认知障碍者** | 无法准确反馈灼痛，**必须他人看护操作** |

## 4. 操作安全

| 项 | 要求 |
|---|---|
| 距离 | 艾条距皮肤 **3–5 cm**，以温热舒适为度 |
| 时长 | 每穴 **10–15 分钟**；勿在同一部位久灸 |
| 温度 | **温热即可，不可追求灼痛或起泡**。古籍亦言「烧到温热，不用烧到很烫」 |
| 通风 | 艾烟需通风；哮喘/呼吸道敏感者注意 |
| 灭火 | 灸后**彻底熄灭火种**（艾绒阴燃易复燃） |
| 灸后 | 2 小时内勿洗冷水、勿吹风；适量温水 |
| 频次 | 保健灸每周 2–3 次；治疗性灸遵医嘱 |

### 起水泡处理（古籍）
> 「若灸后起了水泡，就从皮肤旁用消毒过的针刺一个小洞，把水慢按排出来。**不要把皮肤撕掉免得造成疤痕**」

**现代建议**：小水泡**勿挑破**，保持清洁干燥即可；大水泡、破溃、感染征象（红肿热痛流脓）→ **就医**。

## 5. 何时必须就医（红旗症状）

出现以下任一，**先就医，勿自行艾灸**：

### 腰痛
- 大小便失禁 / 尿潴留
- **鞍区（会阴、大腿内侧）麻木**
- 下肢进行性无力、行走困难
- 外伤后剧痛
- 夜间痛醒、静息痛
- 不明原因体重下降
- 发热伴腰痛
- 肿瘤病史
→ 提示马尾综合征、感染、骨折、肿瘤等，属急症

### 肢冷
- **单侧突然冰冷**，伴苍白/发绀/剧痛 → 警惕动脉栓塞（急症）
- 伴胸痛、气促、大汗 → 警惕心血管事件
- 伴意识改变、言语不清、肢体无力 → 警惕脑血管事件
- 糖尿病患者新发足部溃疡、颜色改变、感觉丧失

### 一般
- 灸后出现严重灼伤、水泡感染
- 症状持续加重或超过 2 周无改善
- 任何你拿不准的情况

## 6. 诚实边界

- 本库为**古籍原文检索**，**不含现代临床试验结论**；古籍记载 ≠ 现代循证证据
- 古籍「主 XXX」是该穴原文适应证罗列，**不等于该穴对现代疾病有效**
- 壮数为古籍记载（如「灸百壮」），**现代实践通常远小于此**，勿照搬
- 库内未载的穴位/病症 → 明说「库内无载」，**不编造古籍原文**
- 涉及**诊断、用药、穴位注射、针刺操作、小儿与孕妇灸法** → 超出本 skill 范围，交由执业医师
- 本文档**不能替代**医嘱；有基础疾病或正在服药者，灸前请咨询医生
